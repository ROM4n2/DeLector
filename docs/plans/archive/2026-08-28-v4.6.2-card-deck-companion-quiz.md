  return S.words.map(w => w.id);

**Interfaces:**
- Consumes: `toggleDeckFlip(event)` on `window` (main.js:665)
- Consumes: `submitCardReview(type, id, grade)` on `window` (main.js:667)
- Produces: clicking front face flips; clicking rating buttons only reviews (no flip)

Root cause: `onclick="toggleDeckFlip(event)"` is on `#deck-active-card` (the entire card container). Fix: move the flip trigger from the container to the front face only. The back face already has a dedicated "↶ 翻回" button with its own onclick.

### Task 4: Fix card deck — intermittent flip-back failure (debounce)

**Files:**
- Modify: `static/js/cards.js:302-314` (`toggleDeckFlip`)

**Interfaces:**
- Consumes: `deckFlipped` (module-level boolean), `deck-active-card` DOM element
- Produces: `toggleDeckFlip` ignores calls within 200ms of previous call

Root cause: On Android, rapid touch events (touchstart→touchend→click with delay) can fire two click events in quick succession. The first flips the card, the second immediately flips it back. The user perceives this as "didn't flip" or "flipped back instantly".

Fix: add a module-level timestamp guard. 200ms is enough to block double-fire while being imperceptible to deliberate taps.

- [ ] **Step 1: Add debounce variable**

In `static/js/cards.js`, near the other module-level state (lines 10-12), add:

```javascript
let _lastFlipTime = 0;
```

- [ ] **Step 2: Add debounce guard in `toggleDeckFlip`**

In `static/js/cards.js`, at the top of `toggleDeckFlip` (line 302-314), add the guard:

```javascript
export function toggleDeckFlip(e) {
  if (e) e.stopPropagation();
  const now = Date.now();
  if (now - _lastFlipTime < 200) return;  // 防 Android 双击事件抖动
  _lastFlipTime = now;
  if (navigator.vibrate) navigator.vibrate(15);
  deckFlipped = !deckFlipped;
  const cardEl = document.getElementById('deck-active-card');
  if (cardEl) {
    cardEl.classList.toggle('is-flipped', deckFlipped);
  }
  const flipBtn = document.getElementById('deck-btn-flip-ctrl');
  if (flipBtn) {
    flipBtn.textContent = deckFlipped ? '↶ 翻回正面 (Space)' : '🔀 翻至背面 (Space)';
  }
}
```
