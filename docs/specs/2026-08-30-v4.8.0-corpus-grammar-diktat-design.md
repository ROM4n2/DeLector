## 1. 背景与核心价值 (Context & Objectives)

DeLector 在 `v4.7.3` 已经夯实了本地优先（Local-First）、离线 0ms 词典、五场域句法拓扑分析、FSRS 记忆排程与 A1 备考工坊的基础设施。

为了将 DeLector 从「伴读辅助工具」全面提升为**「德语学术级全栈备考与语言能力内化工作台」**，`v4.8.0` 将三项高度互补的核心能力进行深度整合：

1. **官方真题精读语料库 (Corpus Engine)**：内置 Goethe A1–B2 / TestDaF 权威样题篇章，解决学习者语料匮乏问题，打通「一键载入 → 句法分析 → 词汇入卡」闭环。
2. **德语语法全景知识图谱与薄弱点雷达 (Grammar Knowledge Map & Radar)**：建立 24 维德语核心语法体系，自动聚合写作批改和自测错题，生成掌握度雷达并支持靶向刷题。
3. **听写与影子跟读工坊 (Diktat & Shadowing Lab)**：利用 `edge_tts_mini` 高清神经语音与 LCS 差异算法，提供听写即时纠错（识别变音、大小写、词尾错误）与 AB 循环影子跟读。

### 3.2 德语语法全景知识图谱与薄弱点雷达 (Grammar Knowledge Map)

#### 24 维语法体系节点定义 (`grammar_taxonomy.py`)

划分 5 大核心支柱，覆盖欧标 A1–C1 全部语法骨架：

1. **Kasus & Rektion (格位支配)**:
   - `kasus_nominativ_akk`: 一格/四格基本支配
   - `kasus_dativ`: 三格支配与人称代词
   - `kasus_genitiv`: 二格所属与二格介词 (während, wegen, trotz)
   - `prep_wechsel`: 9 大双格介词静三动四 (an, auf, hinter, in, neben, über, unter, vor, zwischen)
   - `prep_fixed`: 动词/形容词固定介词搭配 (warten auf, stolz auf)
2. **Deklination (词形屈折)**:
   - `adj_stark`: 形容词无冠词强变化
   - `adj_schwach`: 形容词定冠词弱变化
   - `adj_gemischt`: 形容词不定冠词混合变化
   - `noun_n_deklination`: 阳性弱变化名词 (der Student, der Kunde)
   - `pronomen_relativ`: 关系代词格位变化
3. **Tempora & Verben (时态与动词)**:
   - `temp_perfekt`: 现在完成时 (haben / sein 助动词选择与 Partizip II)
   - `temp_praeteritum`: 过去时强弱变化 (war, hatte, ging)
   - `temp_plusquam`: 过去完成时与时间先后顺序 (nachdem)
   - `verbs_modal_subjektiv`: 情态动词客观与主观用法 (sollen / müssen / dürfen)
   - `verbs_reflexiv`: 反身动词与反身代词 (sich freuen, sich merken)
4. **Satzbau & Syntax (句法拓扑)**:
   - `syntax_v2`: 主句动词第二位与 Vorfeld 占位
   - `syntax_inversion`: 时间/地点前置引起的主谓倒装
   - `syntax_sub_weil_dass`: 从属从句动词置底 (weil, dass, obwohl, wenn)
   - `syntax_infinitiv_zu`: 带 zu 不定式从句结构 (um...zu, ohne...zu, statt...zu)
   - `syntax_partizipial`: 分词短语定语 (Partizip I / II 作为扩展定语)
5. **Passiv & Modus (语态与虚拟式)**:
   - `passiv_vorgang`: 过程被动态 (werden + Partizip II)
   - `passiv_zustand`: 状态被动态 (sein + Partizip II)
   - `passiv_ersatz`: 被动态替代形式 (man, sich lassen, sein + zu)
   - `konjunktiv_2_irreale`: 虚拟式 II (非真实条件句、礼貌表达 hätten/wären/würde)

#### 持久化存储与雷达计算 (`database.py`)

- SQLite 表：`grammar_mastery`
  ```sql
  CREATE TABLE IF NOT EXISTS grammar_mastery (
      node_id TEXT PRIMARY KEY,
      total_trials INTEGER DEFAULT 0,
      correct_trials INTEGER DEFAULT 0,
      last_assessed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  );
  ```
- 评分算法：
  $$
  \text{Mastery Score} = \begin{cases}
  0.50 & \text{if total\_trials} = 0 \text{ (未评估)} \\
  \frac{\text{correct\_trials}}{\text{total\_trials}} \times \min(1.0, \frac{\text{total\_trials}}{5}) & \text{with Wilson score lower bound}
  \end{cases}
  $$
- 路由端点：
  - `GET /api/grammar/radar`：返回 24 节点的掌握度与薄弱项排行榜（Bottom 5）。
  - `GET /api/grammar/drill/{node_id}`：获取针对该语法节点的靶向诊断题集。
  - `POST /api/grammar/record`：记录答题结果并更新掌握度。

### 3.3 听写与影子跟读工坊 (Diktat & Shadowing Lab)

#### 听写对比诊断引擎 (`diktat_engine.py`)

复用 `essay_diff.py` 的快速 LCS 算法，专门针对德语特征分类诊断：

```python
@dataclass
class DiktatDiagnosis:
    original: str
    transcribed: str
    accuracy_score: float  # 0.0 ~ 1.0
    errors: list[dict]     # [{ "type": "UMLAUT"|"CASE"|"WORD_MISSING"|"WORD_EXTRA"|"SPELLING", "expected": str, "actual": str, "pos": int }]
```

- **错误类型自动识别**：
  1. `UMLAUT`：变音丢失或写错（如 `schon` vs `schön`，`mussen` vs `müssen`）。
  2. `CASE`：大小写混淆（如名词首字母未大写 `haus` $\to$ `Haus`）。
  3. `SPELLING`：德语常见拼写混淆（如 `ie` vs `ei`，`ss` vs `ß`，`d` vs `dt`）。
  4. `WORD_MISSING / WORD_EXTRA`：漏词与多词。

#### 影子跟读控制器 (`static/js/diktat.js`)

- 播放管线：通过 `GET /api/audio/tts` 调度 `edge_tts_mini` 生成高保真德语音频。
- 变速模式：提供 `0.75x (精听)`, `0.90x (过渡)`, `1.00x (常速)`, `1.20x (速听)`。
- AB 循环区间重复播放与句子进度微动画。

## 4. 前端交互与视觉规范 (Academic Modern Editorial)

1. **真题语料库抽屉**：
   - 位于 Reader 顶部栏次级导航，纸质折叠式抽屉展开。
   - 带有 CEFR 色标徽章（A1 墨绿、A2 浅蓝、B1 暖琥珀、B2 赭石红）。
2. **语法全景雷达面板**：
   - 位于 Folio 选项卡中，采用 5 列 24 行的墨线矩阵网格与双色进度印章。
   - 掌握度 $\ge 80\%$ 显示古铜绿「已掌握」印章，$\le 50\%$ 显示赭红「需突击」标记。
   - 支持一键点击打开「靶向刷题模态框」。
3. **听写工坊界面**：
   - 输入框具备 1.5px 铸字黑框与温润纸张底色，回车即时触发 Diff 诊断。
   - Diff 标注采用高对比度学术批注样式（非刺眼荧光色）。

## 5. 测试与验证策略 (Test Strategy)

1. **语料库纯度与完整性契约 (`test_corpus.py`)**：
   - 验证所有语料篇章的字数、词汇等级、句子切分及题目索引有效性。
2. **语法图谱与评分算法测试 (`test_grammar_radar.py`)**：
   - 验证 24 维节点映射无重叠遗漏；
   - 验证答题统计记录、Wilson 算法平滑计算及数据库事务安全性。
3. **听写 Diff 诊断精度测试 (`test_diktat.py`)**：
   - 严格测试大小写、变音 `ä/ö/ü/ß`、冠词介词漏词的分类准确率 $\ge 98\%$。
4. **前端模块图与 UI 契约 (`test_frontend_module_graph.py`)**：
   - 确保新增的 `diktat.js` 正确导出/导入，无循环依赖，无孤岛模块。
