# 🇩🇪 DeLector v4.9.0 设计规范：歌德 A1 全真听力与阅读实战考场工坊 (Goethe A1 Hören & Lesen Werkstatt)

> **版本定位**：`v4.9.0`
> **目标**：打造全网最严谨、纯血离线（Local-First）、体验流畅的 **Goethe-Zertifikat A1 (Start Deutsch 1)** 听力 (25分) 与阅读 (25分) 全真模考工坊。

---

## 1. 业务背景与用户价值 (Problem Statement & User Value)

### 1.1 现状与考情痛点

- 歌德 A1 考试中，**听力（Hörverstehen，15题，满分25分）** 与 **阅读（Lesen，15题，满分25分）** 占据总分的 50%；
- 传统备考中，学习者面临三大困境：
  1. **听力缺乏真实考场节奏**：官方 A1 听力录音有严格的播放规则（Teil 1/3 放两遍、Teil 2 仅放一遍，中间包含 5s 读题与 10s 填答停顿），自行练习难以把控节奏；
  2. **听完缺乏逐句精听与原文对照**：做完题后不知道关键信息点在哪里被吞音或漏听，缺少考点词与原文句子级循环回放；
  3. **阅读题型缺乏真实生活语境**：A1 阅读侧重「生活便条判断（Teil 1）」、「网站广告二选一（Teil 2）」和「街头告示标牌（Teil 3）」，PDF 刷题无法划词即时查词与提取词卡。

### 1.2 核心用户旅程 (Core User Journey)

1. **进入 A1 工坊**：学习者在 DeLector 导航栏点击「🎧 A1 备考工坊」，可选择「🎧 听力全真模考」或「📖 阅读实战工坊」；
2. **沉浸式模拟考**：
   - **听力**：点击开始考试，考场音频状态机自动执行「读题提示 $\rightarrow$ 叮声 $\rightarrow$ 音频播放（按题型自动控制播放 1 或 2 遍） $\rightarrow$ 答题倒计时」，学习者快速点选 A/B/C 或 Richtig/Falsch；
   - **阅读**：双栏并排比对真实德语生活便条、网页广告与公共标牌，支持 0ms 划词查词；
3. **即时评分与成绩单**：提交后服务端计算得分，自动换算为 **官方 25 分制标准分**，评定等级（Sehr gut / Gut / Befriedigend / Nicht bestanden）；
4. **逐题精听精读复盘**：查看德汉双语原文（Transkript）、考点生词高亮与深度解析，错题考点词一键收录进 FSRS 卡盒。

```sql
-- 听力成绩表

    id INTEGER PRIMARY KEY AUTOINCREMENT,
    set_id INTEGER NOT NULL,
    score_raw INTEGER NOT NULL,      -- 原始答对题数 (0 ~ 15)
```

## 4. API 路由与契约定义

### 4.1 听力路由 (`routes_a1_hoeren.py`)

- `GET /api/a1/hoeren/sets`: 获取全部 5 套模考卷概览；
- `GET /api/a1/hoeren/set/{set_id}`: 获取指定套题题目（不含 `answer_key` 与 `transcript`，防止做题前泄露）；
- `POST /api/a1/hoeren/grade`: 提交答案并评卷：
  - **Request**: `{"set_id": 1, "duration_seconds": 920, "answers": {"a1_h_01_t1_q01": "B", ...}}`
  - **Response**: `{"score_raw": 13, "score_official": 21.7, "rating": "Sehr gut", "details": [...]}`
- `GET /api/a1/hoeren/history`: 获取听力模考历史与平均分走势。

### 4.2 阅读路由 (`routes_a1_lesen.py`)

- `GET /api/a1/lesen/sets`: 获取 6 套阅读材料列表；
- `GET /api/a1/lesen/set/{set_id}`: 获取指定套题阅读篇章与题目；
- `POST /api/a1/lesen/grade`: 提交阅读答案并换算 25 分制；
- `GET /api/a1/lesen/history`: 获取阅读历史记录。

## 5. 考场音频播放状态机设计 (`a1_hoeren.js`)

歌德 A1 听力播放严格受状态机驱动：

```
[准备就绪 (Ready)]
       │
       ▼ (点击「开始考试」)
[Teil 1 读题 (5s)] ──▶ [播放叮声] ──▶ [第 1 遍音频] ──▶ [停顿思考 (5s)] ──▶ [第 2 遍音频] ──▶ [答题停顿 (10s)] ──▶ [下一题 / Teil 2]
                                                                                                          │
                                                                                                          ▼
[Teil 2 读题 (5s)] ──▶ [播放叮声] ──▶ [第 1 遍音频 (仅 1 遍)] ──▶ [答题停顿 (10s)] ──────────────────────▶ [下一题 / Teil 3]
                                                                                                          │
                                                                                                          ▼
[Teil 3 读题 (5s)] ──▶ [播放叮声] ──▶ [第 1 遍音频] ──▶ [停顿思考 (5s)] ──▶ [第 2 遍音频] ──▶ [答题停顿 (10s)] ──▶ [完成交卷]
```

## 6. 测试与质量契约 (Test Strategy)

1. **`test_goethe_a1_hoeren.py`**：
   - 验证 5 套听力题库结构完整性（题量、分部、音频文本、答案键有效性）；
   - 验证评分逻辑：15 题全对换算为 25.0 分，0 题全错为 0.0 分，四舍五入保留 1 位小数；
   - 验证各端点路由输出安全（做题阶段不泄露答案）。
2. **`test_goethe_a1_lesen.py`**：
   - 验证 6 套阅读题库 90 道题覆盖度与生活场景类型（便条、网页、标牌）；
   - 验证评分与历史记录持久化。
3. **前端安全与无断流测试**：
   - 验证 Edge-TTS 音频请求超时优雅降级与本地音频缓存命中。
