# DeLector v2.1 发布总结与部署指南 (Release Notes)

DeLector（德语文库·精读台账·考点剖析工作台）现已完成 v2.1 重大版本迭代与稳定性验证。

---

## 🌟 核心功能概览

### 1. 德语学术文库与智能分词精读 (Archiv & NLP Reader)
- **德国学术报刊排版 (Gutenberg Broadsheet)**：排版采用 `DM Serif Display` 德式衬线大标题 + 暖白纸张基底（`#faf8f5`）。
- **spaCy 德语 NLP 本地高精分词**：自动识别原型（Lemma）、词性（POS）、冠词性数格（Gender）、欧标分级（A1~C1）及 7 大歌德语法框架（被动态、第二虚拟式、从句连词、分词定语等）。
- **CEFR 欧标难度谱系分布**：实时统计文章总词数、预估研读耗时，并以彩色光谱条展示词汇阶梯构成。
- **防 SSRF 网页安全抓取**：支持输入德语新闻/文章 URL，一键智能提取纯净正文并解析。
- **Edge Neural TTS 神经朗读与跟读伴读 (Shadowing Player)**：双发言人（Katja / Killian）、0.5x~1.5x 变速、单句单循环精听、本地 MP3 智能去重缓存。

### 2. 真实 3D 扑克翻牌盒与卡片库 (3D Poker Deck & Kartei)
- **3D 物理翻牌盒 (Poker Deck Stage)**：居中呈现当前卡片，底层显露 3 层物理叠层阴影。按 **空格键 (Space)** 或点击卡片触发 **`rotateY(180deg)` 3D 翻转**查看背面释义与例句。
- **触控与键盘飞牌**：支持 `A / ←`（上一张）、`D / →`（下一张）及鼠标/触屏物理滑动。
- **双模自由切换**：支持「🎴 扑克牌盒」与「📑 全景目录列表」一键切换。
- **科学掌握机制**：支持卡片误触硬删除（带 3 秒撤回 Toast）与「✓ 斩 (已掌握)」归档隔离。

### 3. 三折风琴学术台账档案 (Leporello Folio Dossier)
- **告别垂直滚轮疲劳**：采用德式学术风琴三折页（`SEITE 01 · 研读总纲` | `SEITE 02 · 轨迹与谱系` | `SEITE 03 · 印章与错题`）横向推拉，首屏完整展现。
- **6 列一体化大字号学术指标行**：连续研读天数、词汇斩获量、语法考点数、精读长文篇数、测验综合准确率、投入学时。
- **每日大师文豪格言**（歌德、维特根斯坦等德语原版格言日替轮播）。
- **集邮式学术成就印章**（Philatelic Stamps）与重点易错词专攻。

### 4. 三大考验自测引擎 (Quiz Engine)
- 🎴 **闪卡记忆自测**
- ✍️ **德语默写自测**（实时拼写判题与原声朗读）
- 🎯 **四选一词义快答**
- 考后自动生成准确率报告与德语鼓励格言。

## 🚀 启动与部署方式

### 方式一：本机 Python 一键启动（推荐）
```bash
# Windows
start.bat
# 或
python start.py
```
脚本将自动检测局域网 IP，并直接调起默认浏览器打开 `http://localhost:8000`。

### 方式二：Docker 容器化部署
```bash
docker compose up -d --build
```
数据（`delector.db`、`progress.db` 及语音缓存 `.cache/`）将自动持久化挂载在宿主机当前目录。

### 方式三：单元测试验证
```bash
pytest
```
当前自动化测试套件：**20/20 全部通过 (100% Green)**。
