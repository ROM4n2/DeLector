### 2. 🗺️ Symbol & Architecture Atlas

#### Data Flow (Monolith)

```text
start.py (launcher, PyInstaller entry)
  └─ server.py (FastAPI app, ~2163 lines, ~60 endpoints)
       ├─ StaticFiles "/"   →  PWA + vanilla ES Modules frontend (no bundler)
       ├─ APIRouters        →  routes_a1 / routes_a1_hoeren / routes_a1_lesen
       │                       routes_corpus / routes_sync
       ├─ database.py       →  SQLite (delector.db + progress.db), FSRS, backup/restore
       ├─ nlp.py            →  spaCy pipeline + pure_python fallback
       ├─ linguistics.py    →  180+ irregular verbs, Komposita splitter, ext vocab
       ├─ writing_rules.py  →  local grammar rule engine
       ├─ syntax_tree.py    →  Feldermodell topology + clause AST
       ├─ essay_diff.py     →  sentence-level diff/merge for AI polish
       ├─ security.py       →  SSRF guard, HTML extraction, RSS parsing
       ├─ edge_tts_mini.py  →  stdlib Edge TTS WebSocket client
       └─ *_dict.py         →  offline content/data tables
           └─ LLM tier      →  httpx → OpenAI-compatible Chat Completions
                              (default DeepSeek deepseek-v4-flash; convenience only)
```

Static assets mounted last as catch-all with `Cache-Control: no-cache` middleware on frontend assets.

#### State & Persistence

- **SQLite, two databases**: `delector.db` (content — articles, cards, essays, settings) + `progress.db` (analytics — study_log, quiz_log, a1 exam records). WAL mode is persistent in DB header (not set per-connection in code).
- **Ephemeral state**: module-global dicts (`_pending_backup`, `_pending_wb`, `_sync_sdp_cache` with TTL). No mutexes — single-user design + GIL provides safety.
- **Frontend**: single mutable `state` in `core.js`, direct DOM render, `localStorage` for UI prefs. Server is source of truth.
- **Config precedence**: DB `app_settings` table → `.env` / env vars → code defaults. API key never returned in `GET /api/settings`, never included in backups.

### 3. 🚨 Invariants & Gotchas (Non-Negotiable Red Lines)

- ❌ **No Secret Leakage (MUST)**: Pre-commit hook in `.githooks/pre-commit` enforces regex + magic-byte scanning (API keys, JWT, PEM, JKS, PKCS12). Activate with `git config core.hooksPath .githooks`. **Never use `--no-verify`**.
- ❌ **4-Place Sync for New Backend Modules (MUST)**: Any new `routes_*.py` / `*_dict.py` module must be added to (a) `package_windows.py` hidden imports, (b) Linux PyInstaller CI step, (c) macOS PyInstaller CI step, (d) Android CI `cp` list. Missing any = packaged app/APK silently omits it. **v4.8.1 was exactly this failure** (`routes_corpus` missing from APK).
- ❌ **No Unbuffered Non-UTF8 Windows Output (MUST)**: Entrypoints must enforce `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`. CI sets `PYTHONIOENCODING=utf-8`.
- ❌ **No Async TTS Audio Load Race (MUST)**: `playWord()` cleanup must NOT call `_ttsAudio.load()` after `removeAttribute` to prevent async error event collisions. Verified by `test_german_workbench.py::test_playword_cleanup_does_not_reload_audio`.
- ❌ **No Accidental Directory Symlinks in Git Bash (MUST)**: Always use `MSYS=winsymlinks:nativestrict ln -s /target /link` on Windows — plain `ln -s` silently copies.
- ❌ **No AI Slop UI (MUST)**: Follow Academic Modern Editorial principles — no generic neon gradients or dark glassmorphism. Maintain warm paper tones (`#FAF8F5`), 1.5px ink strokes, asymmetric grid (`0.78 : 1.22`), and 44px minimum touch targets.
- ❌ **Dangling Identifiers Kill Module Graph (MUST)**: The window-hook exposer pattern — any bare identifier used without import throws a `ReferenceError` that kills the entire module → all interaction dead, page renders fine. Caught by `test_frontend_module_graph.py::test_window_hook_exposer_identifiers_are_bound`. **v4.8.3 regression was exactly this class** (undefined window callback in `main.js` killed all Android taps).
- ✅ **Local-First & Offline-First (MUST)**: All core dictionary searches, morphological analysis, syntax trees, FSRS scheduling, and A1 grading must run 100% locally with 0ms latency. LLM is a convenience tier only.
- ✅ **Android Chaquopy Lock (MUST)**: Keep Python 3.10 + minSdk 24 + arm64-v8a compatibility. All spaCy model fallbacks must gracefully support `pure_python` mode. Downgrades/omissions are silent — CI has APK content verification to catch them.
- ✅ **Android Loopback-Only Bind (MUST)**: `start.py:get_bind_host()` returns `127.0.0.1` on Android (prevents exposing `POST /api/settings` to LAN), `0.0.0.0` on desktop (LAN access is intentional feature). Sensitive endpoints additionally gated per-request by `_require_localhost`.
- ⚠️ **SSRF Guard Has IPv6 Edge Cases**: `security.py` unwraps IPv4-mapped/6to4/Teredo addresses and pins `2001::/23` deny block (because `ipaddress` private-range table changed between Python 3.11.8 and 3.11.16). Redirects followed manually hop-by-hop with SSRF check before each request.
- ⚠️ **Backup tokens are TTL-reusable (10 min), not single-use**: Android WebView can't handle `blob:` downloads, so `ExportSaver.java` re-fetches the URL. `Cache-Control: no-store` prevents WebView from caching a 404 body as a fake backup.
- ⚠️ **SQLite WAL Persistence**: WAL is persistent in the DB header once set (no `PRAGMA journal_mode=WAL` in code). Don't copy `.db` alone — include `-shm` and `-wal` or checkpoint first. Cross-DB atomicity for restore uses file-level snapshot/rollback via `_db_snapshot_guard()`.
- ⚠️ **versionCode scheme**: `major*10000 + minor*100 + patch`. Changed after 3.10.0 vs 4.0.0 both computed to 400, which would have blocked upgrade installs.
- ⚠️ **`DeLector.spec` is NOT canonical**: It's gitignored (`*.spec`) and has hardcoded `D:/Code/DeLector` paths. Use `package_windows.py` for Windows builds.
- ⚠️ **No TODO/FIXME markers**: Convention is version-tagged Chinese rationale comments (e.g. "v4.7.3 修"). Real-device Android testing is pending per README — Java layer can't be compiled locally without Android SDK.

### 4. 📦 Existing Utility Wheels (Do NOT Reinvent)

- `linguistics.lookup_lemma(word)`: Comprehensive 5-tier morphological lookup and irregular verb resolution.
- `linguistics.split_compound(word)`: Recursive dynamic-programming German compound noun decompounding.
- `prep_dict.lookup_prep_collocations(lemma)`: Instant lookup for verb/adjective + preposition + case bindings.
- `writing_rules.analyze_essay_text(text, nlp)`: High-precision rule-based grammatical agreement and case checker.
- `security.guard_loopback_only(request)`: Fast middleware check restricting sensitive mutations to localhost.
- `edge_tts_mini.synthesize_mp3_sync(text, voice, rate)`: Stdlib-only TTS synthesizer (Edge WebSocket) — no aiohttp dependency needed.
- `core.apiFetch(endpoint, options)`: Standard frontend HTTP client wrapper with error handling and toast notifications.
- `database._db_snapshot_guard(db_paths)`: Context manager for file-level atomic restore across multiple SQLite files.
