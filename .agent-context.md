### 3. 🚨 Local Engineering Red Lines & Gotchas

- **StaticFiles Catch-All Order (MUST)**: `app.mount("/", StaticFiles(directory=STATIC_DIR, html=True), name="static")` MUST be the last route in `server.py`. Mounting before any router causes all API endpoints to return 405 Method Not Allowed.
- **NLP Silent Degradation Trap (CRITICAL)**: If spaCy fails to load, DeLector silently falls back to pure Python regex. Pure Python fallback loses dependency parse, topological fields, AST, and separable verb lemmatization (`steigt...ein` wrongly treated as `steigen` B1). Always verify `nlp_engine` in `/api/settings`.
- **4-Place Sync for New Backend Modules (MUST)**: Any new `routes_*.py` / `*_dict.py` module MUST be added to:
  1. `package_windows.py` hidden imports
  2. Linux PyInstaller CI step
  3. macOS PyInstaller CI step
  4. Android CI `cp` list
     Missing any causes silent import failure on packaged builds/APK (v4.8.1 historical incident).
- **Android Chaquopy Lock & Loading (MUST)**:
  - Keep Python 3.10 + minSdk 24 + arm64-v8a compatibility.
  - Gradle MUST contain `extractPackages "spacy", "thinc", "de_core_news_sm"`.
  - Never call `spacy.load("name")` on Android (fails with E050); must use `importlib.import_module(name).load()`.
  - Android bind host must strictly be `127.0.0.1` (loopback only) to prevent unauthorized API key/base_url overwrites over LAN.
  - No network requests during module import phase.
- **Security & Authorization (MUST)**:
  - Mutation endpoints (`POST /api/settings`, delete actions, backup restore, `PUT /api/wb/state`) require `_require_localhost` (loopback only, 403 over LAN).
  - External URL ingestion strictly enforces SSRF protection via `is_safe_public_url()` with pinned `2001::/23` deny blocks.
  - WebRTC signaling endpoints (`routes_rtc.py`) require valid `X-WB-Key` authentication.
- **Dangling Identifiers Kill Module Graph (MUST)**:
  - In frontend ES modules, bare unimported identifiers throw runtime `ReferenceError` during module evaluation and kill the entire UI. Guarded by `tools/ia_dom_mount_probe.mjs` and `test_frontend_module_graph.py`.
