### 3. 🚨 Invariants & Gotchas (Non-Negotiable Red Lines)

- ❌ **No Secret Leakage (MUST)**: Pre-commit hook in `.githooks/pre-commit` enforces regex scanning. Never use `--no-verify`.
- ❌ **No Unbuffered Non-UTF8 Windows Output (MUST)**: Entrypoints must enforce `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`.
- ❌ **No Async TTS Audio Load Race (MUST)**: `playWord()` cleanup must NOT call `_ttsAudio.load()` after `removeAttribute` to prevent async error event collisions.
- ❌ **No Accidental Directory Symlinks in Git Bash (MUST)**: Always use `MSYS=winsymlinks:nativestrict ln -s /target /link` on Windows.
- ❌ **No AI Slop UI (MUST)**: Follow Academic Modern Editorial principles — no generic neon gradients or dark glassmorphism. Maintain warm paper tones (`#FAF8F5`), 1.5px ink strokes, asymmetric grid (`0.78 : 1.22`), and 44px minimum touch targets.
- ✅ **Local-First & Offline-First (MUST)**: All core dictionary searches, morphological analysis, syntax trees, and FSRS scheduling must run 100% locally with 0ms latency.
- ✅ **Android Chaquopy Lock (MUST)**: Keep Python 3.10 + minSdk 24 compatibility in mind; all spaCy model fallbacks must gracefully support `pure_python` mode.

### 4. 📦 Existing Utility Wheels (Do NOT Reinvent)

- `linguistics.lookup_lemma(word)`: Comprehensive 5-tier morphological lookup and irregular verb resolution.
- `linguistics.split_compound(word)`: Recursive dynamic-programming German compound noun decompounding.
- `prep_dict.lookup_prep_collocations(lemma)`: Instant lookup for verb/adjective + preposition + case bindings.
- `writing_rules.analyze_essay_text(text, nlp)`: High-precision rule-based grammatical agreement and case checker.
- `security.guard_loopback_only(request)`: Fast middleware check restricting sensitive mutations to localhost.
- `edge_tts_mini.synthesize_mp3_sync(text, voice, rate)`: Stdlib fallback TTS synthesizer without external dependencies.
- `core.apiFetch(endpoint, options)`: Standard frontend HTTP client wrapper with error handling and retry mechanics.
