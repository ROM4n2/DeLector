## 概述

十一月上旬是 DeLector 完成从「功能解耦与单体拆分」迈向「完整伴学 Agent 闭环 + 前端设计系统规范化 + 视觉回归全自动闸门」的跨越周期。期间密集发版六次（**v5.20.0 → v5.22.0**），并完成 ADR 决策链（**ADR-0025 ~ ADR-0030**）。

核心主线由五大工程战役构成：
1. **伴学 Agent 运行时闭环（ADR-0025）**：Go/Python 混合双内核、SSE 7 类事件契约对齐、洋葱中间件调度、上下文动态压缩（Pi 范式）、多动作 HITL（写作建议与周学习目标逐条确认/拒绝）以及 SSE 断流凭 Session-ID 优雅恢复（v5.20.0 ~ v5.21.1）。
2. **Android 主路径与跨端工程互锁（ADR-0028）**：确立 Android 必须以 spaCy `de_core_news_sm` 为主分析路径（用户裁定「宁漏勿错」，纯 Python 标注错误绝不妥协；启动后台预热 + 首次同步兜底；硬失败禁下载）；建立 x86_64 完整模拟器变体；落地 `DELECTOR_PORT_FILE` 跨进程端口握手，彻底消除 Go supervisor 与 Python 端口碰撞导致的静默降级（v5.21.1 ~ v5.22.0）。
3. **前端去 Emoji 与编辑设计系统（ADR-0029）**：全站 4 垂直批次去 Emoji 清零（390 处字形装饰清空），规范化引入 Lucide 纯静态 SVG vendor，角色全量 SVG 化；建立「编辑排版节奏」，重塑 exam、reader、cards、settings 与 writer 视觉层次。
4. **前端动效与生机系统（ADR-0030）**：加法动效分层，确立全站仅 7 处常驻循环动画白名单（其余全部静态降级）；提供全局 `prefers-reduced-motion` 兜底；落地桌宠 P1（气泡钳位）→ P2（禁停区自动让位）→ P3（生机纯函数状态机）→ P4（自由漫游回位）。
5. **视觉回归基建与全站换皮收口**：建立 12 界面 × 3 宽度本地 CDP 截图矩阵与 12 控件 computed-style 基线；落地 CSS 9 段零差异拆分与构建同步闸；静态字面量预算闸与亮暗对比度闸（主站 + workbench 双闸全绿）；词卡抽屉单行复习台账（读侧单条 SQL 逆运算去重，零新增列）；存量文章按需惰性重算（`PROCESSED_JSON_VERSION` 3.6.0 带备份表与逐字恢复工具）。

## 踩坑与教训

1. **平台路径排序大小写敏感度差异导致指纹漂移（11-08）**：
   - 现象：Windows 上构建生成的 APK 静态资产指纹是 `3061541188d7`，但在 Android 设备运行期动态计算却为 `cc1efb3c37f8`，导致每次启动均判定资产过期并重复解包。
   - 根因：`sorted(Path)` 在 Windows（NTFS）下大小写不敏感，而在 Linux/Android 下大小写敏感，导致 `icons/README.md` 与 `icons/lucide-sprite.svg` 排序相反。
   - 解法：固定排序键为 `rel.as_posix()`，并补充跨平台路径排序一致性守卫测试。
2. **Windows 下 Go 与 Python 绑定冲突导致静默 404（11-07）**：
   - 现象：8000 端口被占时，Python 自动顺延到 8002；Go supervisor 也绑定 8002。Windows 允许 Go 绑定 `127.0.0.1:8002` 与 Python 绑定 `0.0.0.0:8002` 共存，导致请求全落入 Go 内核，全 API 404，且启动日志仍报告托管成功。
   - 解法：引入 `DELECTOR_PORT_FILE` 文件握手；Go 端口顺延区间固定为 8011–8015（与 Python 8000/8002–8010 互斥）；健康检查校验服务身份。
3. **CSS 动画读取时间窗口与过渡中间值假象（11-07）**：
   - 现象：控件聚焦 40ms 后通过 CDP 抓取 outline 判定样式未生效。
   - 根因：控件存在 `transition: all .15s`，40ms 处抓取到的是用户代理焦点环向自定义焦点环过渡的中间计算值。
   - 解法：去除 `transition: all` 改为具名属性过渡；CDP 探针读取计算样式必须等待过渡完成（≥360ms）。
4. **内联 HTML 事件找不到 ES Module 作用域（11-08）**：
   - 现象：`submitChoice(...)` 内联 onclick 在点击时抛 `ReferenceError`，无视觉正误反馈。
   - 根因：页面脚本已迁为 ES Module，函数未暴露至 `window` 全局对象。
   - 解法：统一走 `window.selectChoiceOption` 桥接，并在静态契约守卫中覆盖前端调用入口。
5. **DOM 桩在 node:vm 沙箱中保真度不足（11-07）**：
   - 现象：卡片重构引入 `container.dataset` 导致多个测试探针报 `TypeError`。
   - 解法：探针 DOM 桩必须提供真实 DOM 必有的基础属性（`dataset`、`querySelector`、`setAttribute`），遵循「桩保真、断言不放宽」纪律。
